# Aprende con Lupi

Juegos y repaso para 3.º de Primaria: Mates, Lengua, Ciencias e Inglés.

- `index.html` es la portada con todos los juegos.
- `mates.html` tiene los temas, el MODO EXAMEN y la zona de padres.
- En `imprimir/` están los planes de estudio, los exámenes y las fichas en PDF.

El progreso de cada niño se guarda en su propio navegador.
